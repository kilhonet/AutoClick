## 概述

有些工作需要把同一个按钮点上几十、几百次。AutoClick 可以代替你完成这些点击。

先设定要按的按键(左键 · 右键 · 滚轮)、单击还是双击、每隔多久点一次,然后按快捷键(默认 **F3**)即可开始。再按一次同一个快捷键就会停止。即使你正在看其他程序,快捷键也同样有效,所以不必把 AutoClick 窗口放在最前面。

如果不是只点一个地方,而是要依次点击多个位置,请使用 **记录**。把鼠标移到要点击的位置后按快捷键(默认 **F4**),该位置就会一行一行地加入列表;勾选 **使用记录** 后运行,就会按列表顺序轮流点击。

## 主要功能

- **鼠标自动点击** — 以单击或双击的方式反复按下左键 · 右键 · 滚轮键。
- **间隔范围** — 可以像每 1 秒一次这样固定间隔点击,也可以在 1 秒到 3 秒之间每次以不同的间隔点击。精确到 1/100 秒。
- **全局快捷键** — 即使正在使用其他程序,也能用一个快捷键开始和停止。按键可以改成任意组合。
- **记录** — 制作按顺序点击多个位置的模式,并为每个位置单独设定按键 · 点击方式 · 间隔。
- **保存模式** — 把记录保存为文件,需要时再打开。上次的列表会在下次启动时原样恢复。
- **重复次数** — 点击达到设定次数后自动停止。留空则一直点击,直到你停止为止。
- **保持光标** — 点击指定位置后,把鼠标光标移回原来的位置。
- **通知** — 开始和停止时用 Windows 通知提醒你。开始通知中会同时显示停止用的快捷键。
- **深色模式** — 跟随 Windows 的应用模式(浅色 · 深色)切换界面颜色。
- **8 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 西班牙语。

## 使用方法

### 快速上手

1. 启动 AutoClick。
2. 在 **鼠标设置** 中选择要按的按键(**鼠标**)、单击还是双击(**点击**)以及点击间隔(**延迟**)。初始设置为每 1 秒按一次左键。
3. 把鼠标光标移到要点击的位置。
4. 按 **F3**。底部的状态栏变为 **正在运行**,开始按设定的间隔点击该位置。
5. 完成后再按一次 **F3**。状态栏恢复为 **等待中**。

### 界面构成

| 元素 | 作用 |
|---|---|
| **主页** · **测试** · **赞助** | 顶部菜单。**测试** 会打开一个可以试点击的鼠标测试页面 |
| KILHO.net 标志 | 打开 AutoClick 介绍页面 |
| **鼠标设置** | **鼠标**(左 · 右 · 滚轮) · **点击**(单次 · 双击) · **延迟**(点击间隔,两个框构成范围) |
| **快捷键设置** | **开始/结束**(默认 F3) · **添加记录**(默认 F4) |
| **其他设置** | **重复** · **位置**(保持 · 修改) · **使用提示**(使用 · 不使用) |
| **记录** 列表 | 按顺序列出要点击的位置。列为 **位置** · **鼠标** · **点击** · **延迟** |
| **使用记录** | 勾选后,运行时按列表顺序点击 |
| **清空** · **打开** · **保存** | 清空整个列表 / 打开已保存的列表 / 把列表保存为文件 |
| 状态栏 | **等待中** 或 **正在运行** |

### 这种情况怎么办

**一直点击同一个位置**
把光标放在要点击的位置后按 **F3**,就会一直点击开始时光标所在的那个位置。**位置** 为 **保持** 时,每次点击后都会把光标移回原处,所以在此期间把鼠标移到别处,点击的位置也不会改变。

**跟着光标点击**
把 **位置** 改为 **修改** 后,点击的不再是开始时的位置,而是每次点击那一刻光标所在的位置。适合在运行中移动鼠标、随时改变点击目标的场合。

**让每次的间隔稍有不同**
在 **延迟** 的两个框中填入范围。例如填入 `00:01.00` 和 `00:03.00`,每次会在 1 秒到 3 秒之间以不同的间隔点击。两个框相同时,间隔始终不变。框的格式为 `分:秒.1/100秒`,只需依次输入数字就会自动对齐到相应位置,最长可设为 99 分 59.99 秒。

**只改前一个框可以吗**
修改前一个框后切换到其他框时,后一个框会跟着前一个框调整。后一个框一旦由你亲自修改,就会保持该值;因此想设定范围时,先填前一个框,再填后一个框即可。如果后一个框比前一个框小,会被调整为前一个框的值。

**只点击指定次数后停止**
在 **重复** 中输入数字。点击达到该次数后会自动停止;如果 **使用提示** 已开启,会显示"已达到重复次数,运行结束。"的通知,同时任务栏上的 AutoClick 会闪烁提醒。框留空(淡淡地显示 **无**)时会一直点击,直到你停止为止。双击也算作一次。

**依次点击多个位置(记录)**
1. 在 **鼠标设置** 中选择按键 · 点击方式 · 延迟。
2. 把光标移到第一个位置并按 **F4**。**记录** 列表中会加入一行,包含该位置以及当前选择的按键 · 点击方式 · 延迟。
3. 在下一个位置同样按 **F4**。如果想让某一行使用不同的按键或延迟,在按 **F4** 之前修改 **鼠标设置** 即可。
4. 勾选 **使用记录** 后按 **F3**,会从第一行开始依次点击,最后一行之后再回到第一行。列表中会标出当前正在点击的行。

每一行的 **延迟** 是点击该位置后、进入下一行之前等待的时间。

**调整记录顺序或只删除一行**
在列表中右键点击该行,会出现 **上移** · **下移** · **删除**。要清空整个列表,点击 **清空** 并在确认窗口中点击 **是**。运行中无法修改列表,请先停止。

**保存多个模式,按需选用**
用 **保存** 把当前列表保存为文件,需要时用 **打开** 载入。为每项工作各保存一个模式文件会很方便。即使不另外保存,关闭 AutoClick 时的列表在下次启动时也会原样恢复。旧版本保存的记录文件也能直接打开。

**看懂记录列表中的延迟**
单个间隔显示为 `00:01.00`,范围显示为 `01:01.00~05:03.00`,与输入框的格式相同。如果范围较长被截断,可以把鼠标停在上面查看,或拖动列标题之间的分界线加宽列。

**想更改快捷键时**
点击 **快捷键设置** 中的框,会变成"请按键"。这时按下要用的键,或与 **Ctrl** · **Alt** · **Shift** 组合的按键(例如 **Ctrl+Shift+F3**),就会立即更改并保存。在框中按 **Esc** 会清空该快捷键(**无**)。请选择不与游戏或其他程序常用按键冲突的键。

**与其他程序的快捷键冲突时**
如果其他程序已经在使用同一个键,AutoClick 会提示你。改用其他键或关闭那个程序即可;那个程序关闭后重新启动 AutoClick,原来的键就会重新生效。如果两个快捷键填入同一个键,会提示该键已被另一个功能使用,并且不会接受。

**不需要通知时**
把 **使用提示** 改为 **不使用**,就不会再显示开始 · 停止 · 重复完成的通知。开启时,开始通知会像"再次按相同快捷键即可结束 (F3)"这样告诉你停止用的键,忘记快捷键时很有帮助。

**按下滚轮键**
把 **鼠标** 选为 **滚轮** 时,不是滚动滚轮,而是按下滚轮键(中键)。适用于需要用到中键的场合,例如在浏览器中用新标签页打开链接。

**开始之前先试一试**
点击顶部的 **测试**,浏览器中会打开一个鼠标测试页面,分别统计左键 · 滚轮 · 右键的单击和双击次数。可以先改变按键 · 点击方式 · 延迟,确认点击是否符合预期。

**运行中想修改设置**
运行中为防止误改,输入框会被锁定。用 **F3** 停止,修改后再按 **F3** 即可。

**已经在运行时又启动了一次**
AutoClick 只能运行一个。再次启动不会打开新的,而是把已经打开的窗口调到最前面。窗口标题中会显示当前版本。

## 设置

没有单独的设置窗口。快捷键 · **位置** · **使用提示** 一经修改就会被记住,记录列表在关闭时保存,下次启动时恢复。以下内容由 AutoClick 自动跟随。

| 项目 | 跟随 |
|---|---|
| 语言 | Windows 区域设置(不支持的语言显示英语) |
| 界面颜色 | Windows 应用模式(浅色 · 深色) — AutoClick 运行期间更改也会立即跟随 |
